# Tuple

**What it is:** A remote pair-programming app for macOS and Windows built around low-latency, up-to-5K screen sharing, crisp audio, and seamless shared remote control.

**Problem it solves:** Gives a solo developer a purpose-built way to pair with a freelance client, mentor, or open-source collaborator that feels like sitting at one keyboard, instead of fighting blurry, laggy generic screen sharing.

**When I'd reach for it:**

- Walking a freelance client or contractor through a codebase in real time.
- Getting unstuck on a gnarly bug where a second set of eyes breaks the logjam faster than going solo.
- Mentoring or pairing on an open-source project, where Tuple grants free licenses to OSS contributors.

**When I wouldn't:**

- Straightforward, well-defined solo implementation work, where pairing adds overhead without proportional benefit.
- When the budget cannot absorb a $30/month subscription for a tool only used during pairing sessions.

**Pricing posture:** No free tier, only a 14-day trial; the Teams plan is $30/month per user, with free guest pairing for external collaborators and a 90 percent first-year discount for early-stage startups.

**Reality check:** The product is well-reviewed for crisp screen sharing, a light native C++ engine, and end-to-end encryption that keeps sessions off Tuple's servers. The real catch is fit, not reliability: it is paid-only, Linux support is an early alpha, there is no built-in editor or IDE integration, and sustained pairing is cognitively draining, so for routine solo execution work an AI assistant often covers the gap.
