# Taxonomy

The controlled vocabulary of problem areas. Research assigns a tool's
`problem-areas` frontmatter only from this list. A tool may belong to more
than one area.

Adding a new area is a human decision. If the refresher finds a tool that
fits nothing here, it does not invent an area; it logs the tool in
`CHANGELOG.md` for a human to map or to extend this list.

## Areas

- `auth`: user authentication, identity, session management.
- `security`: rate limiting, bot protection, API key management, code
  security scanning.
- `ci-cd`: build pipelines, continuous integration, deployment automation.
- `hosting-deploy`: application hosting, deployment platforms, domains, DNS.
- `database`: managed databases and data stores.
- `backend-platform`: backend-as-a-service, all-in-one app backends.
- `cms`: content management, headless CMS.
- `error-monitoring`: error tracking, telemetry, application observability.
- `product-analytics`: product and usage analytics, SEO analysis.
- `feature-flags`: feature flagging and experimentation.
- `email-messaging`: transactional email, SMS, notifications.
- `ui-components`: frontend component libraries and widgets.
- `design-tooling`: design inspiration, mockups, design-to-code.
- `media-optimization`: image and asset optimization and delivery.
- `dev-workflow`: developer workflow tools, code review flow, pairing.
- `cost-optimization`: cloud cost reduction and management.
- `ai-code-review`: AI-powered code review.
- `ai-coding-agents`: AI coding agents, app builders, vibe-coding platforms.
- `ai-agent-infra`: runtime infrastructure for AI agents, such as cloud
  browsers, sandboxes, and GPUs.
- `ai-apis`: hosted AI APIs for generation, such as voice, image, and model
  inference.
- `ai-web-data`: web search, scraping, and data sourcing for AI apps.
- `background-jobs`: background workers, job queues, scheduled tasks.
