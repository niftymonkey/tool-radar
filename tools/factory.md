# Factory

**What it is:** An agent-native development platform whose autonomous agents, called Droids, run real dev tasks (editing files, running commands, pushing changes) from the CLI, browser, and editor.

**Problem it solves:** Lets you delegate a whole ticket to an agent that returns a finished implementation and a reviewable diff, instead of pair-typing with an autocomplete tool.

**When I'd reach for it:**

- A side project where you want to hand off a well-scoped feature and review the result later, even from mobile.
- Ticket-driven work wired through GitHub, Jira, or Linear that you want an agent to pick up and finish.
- Switching freely between Claude, GPT, and Gemini without changing tools.

**When I wouldn't:**

- A messy repo with weak tests and no review habit, where the agents tend to add more bugs than they fix.
- Quick in-editor assistance, where Factory's delegation overhead feels heavy versus Cursor or Copilot.

**Pricing posture:** No free tier. Pro is $20/month, Plus is $100/month, Max is $200/month; Teams and Enterprise are custom-priced.

**Reality check:** Reviewers say Droids genuinely do the work but only pay off with disciplined CI, testing, and review practices; vague prompts or messy repos produce hallucinated logic and missed edge cases. Token costs can climb fast if usage is unmanaged, the learning curve is steep, and early-2026 write-ups still flag slow response times and rough UX.
