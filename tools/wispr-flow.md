# Wispr Flow

**What it is:** A voice-to-text dictation app that turns natural speech into clean, AI-formatted writing inside any app on Mac, Windows, iOS, and Android.

**Problem it solves:** Lets a solo developer write PR descriptions, commit messages, issue writeups, comments, and AI-coding prompts by speaking, at roughly four times typing speed, with filler words and false starts cleaned up automatically.

**When I'd reach for it:**

- Drafting long-form prose (issue writeups, PR explanations, docs) faster than typing allows.
- Feeding half-formed plans to an AI coding assistant in Cursor or VS Code by voice.
- Reducing keyboard load when wrist strain or RSI makes heavy typing painful.

**When I wouldn't:**

- Confidential code or client data under NDA, since audio and active-window screenshots are sent to cloud servers.
- Offline work or flaky connections, because there is no local processing mode.

**Pricing posture:** Free Basic tier capped at 2,000 words per week on desktop; Pro is $15/month per user, or $12/month billed annually, for unlimited words.

**Reality check:** All transcription is cloud-only, and reviewers flag that the context-aware feature captures periodic active-window screenshots, a structural dealbreaker for sensitive work. Independent reviews report a 2.7/5 Trustpilot score, roughly 800MB RAM and 8 percent idle CPU on older Macs, and an Electron Windows build that has frozen target apps including VS Code. There is a real one-week learning curve, and local-first tools like SuperWhisper win on privacy.
