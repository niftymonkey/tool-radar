# Research queue

Ad-hoc requests for the refresher. Add a bullet under New to research a
tool not yet in the catalog, or under Re-research to refresh an existing
entry. Use a tool's slug (its filename without `.md`) for re-research
items. The refresher checks off processed items and moves them to Done with
the run date.
